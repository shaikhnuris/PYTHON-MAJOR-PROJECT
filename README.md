# 🎨 Image Craft – Python Image Editing App

Image Craft is a beginner-friendly Python project that allows users to resize images, convert image formats, and apply grayscale effects using the Pillow library.

## 🚀 Features

- **Image Resizer & Compressor:** Resize images to custom width and height and save them with optimized JPEG quality.
- **Image Format Converter:** Convert images into formats such as PNG, JPG, JPEG, and WEBP.
- **Grayscale Effect:** Apply a grayscale effect to images.
- **File Path Validation:** Check whether the input image exists before processing.
- **Automatic File Extensions:** Add supported image extensions automatically when needed.
- **Error Handling:** Handle common errors during image processing.

## 🛠️ Technologies Used

- Python
- Pillow (PIL)
- OS Module

## 📋 Requirements

- Python 3.8 or later
- Pillow library

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd YOUR_REPOSITORY_NAME
```

**3. Install the required library**

```bash
pip install Pillow
```

## ▶️ How to Run

Run the Python file:

```bash
python image_craft.py
```

Replace `image_craft.py` with your actual Python filename if it is different.

Enter the image path when prompted and choose an operation:

1. Image Resizer and Compressor
2. Image Format Converter
3. Image Effect App (Grayscale)

Follow the instructions displayed in the terminal.
